# QAチェックリスト（クラウド必須）

## 新規ユーザー
- [ ] オンライン状態でログインできる（APIトークンを入力）。
- [ ] 学習を開始できる（クイック練習/今日の復習）。
- [ ] 回答後の進捗が即座に反映される（進捗画面）。
- [ ] ブラウザを変えても同一ユーザーIDで進捗が復元される。

## 旧ユーザー移行
- [ ] 旧 localStorage が検出され「旧データをクラウドへ移行」が表示される。
- [ ] 移行ボタンでクラウドに取り込み、完了後にローカルデータが削除される。
- [ ] 二重取り込みが防止される（移行済み表示）。

## オフライン
- [ ] オフライン時に学習開始できない旨の表示が出る。
- [ ] オフライン時にログイン・移行がブロックされる。

## 模擬テスト
- [ ] 模擬テストの途中保存→再開がクラウドで復元できる。
- [ ] 結果記録後に弱点復習へ遷移できる。
